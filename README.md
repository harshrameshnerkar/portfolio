## 🚀 Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

Open **`http://localhost:3000`** in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
